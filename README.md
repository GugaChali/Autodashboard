# 📊 AutoDashboard

> 🚧 **Status do Projeto:** Em desenvolvimento ativo.

Aplicação web desenvolvida em **Python** e **Streamlit** com o objetivo de automatizar a análise exploratória de dados e gerar visualizações interativas a partir de planilhas.

## 🎯 Objetivo
Criar uma ferramenta simples e intuitiva onde qualquer pessoa possa carregar uma base de dados (`.csv` ou `.xlsx`) e visualizar métricas e gráficos sem precisar escrever código.

## 🛠️ Tecnologias
- **Python**
- **Streamlit** (Interface web)
- **Pandas** (Manipulação e análise de dados)
- **Plotly** (Gráficos interativos)

## ⚙️ Como rodar o projeto localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com
   cd Autodashboard
   ```

2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

3. Execute a aplicação:
   ```bash
   streamlit run main.py
   ```
